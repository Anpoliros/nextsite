# Routing

静态生成器只发布主页和文章两种内容页。分类与 tag 页面已移除。

## 路由表

| URL | 页面 |
| --- | --- |
| `/` | 贴纸主页，浏览器内按分类筛选和分页 |
| `/<category>/<slug>/` | 文章 |
| `/about/` | 使用文章模板渲染 `about.md` |
| 未生成路径 | 404 |
| `/healthz` | 静态服务健康检查 JSON |

## 实现视角

`build/routes.ts` 读取内容并创建异步路由清单，`build/photos.ts` 准备相册。主页数据包含全部文章摘要，按 12 篇分页；书签筛选先筛选全量文章，再分页。无分类和 tag 链接；文章元信息中保留普通文本。

分类沿用目录第一层，slug 沿用文件名。URL 片段编码、输出目录解码，继续检查路由重复和目录越界。`/404/` 对应产物 `404.html`。静态文件服务对已生成页面补齐尾部斜线。

## 修改指南

修改页面类型时同步更新 `src/site/types.ts`、`src/site/Page.tsx` 和 `build/routes.ts`。正文里的作者手写链接保留原文，旧分类/tag 链接会返回 404。

## 验证方式

构建后运行 `npm test`；确认分类/tag URL 返回 404，主页筛选、相册来源和篇间导航正常，任意文章路径可直接打开。
